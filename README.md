#Sistem Penilaian dan Rekomendasi kelulusan

## Deskripsi
Program yang merupakan script Bash untuk menyimulasikan sistem penilaian  mahasiswa

### Fitur
- Input nama
- Input nilai teori & praktikum
- Validasi nilai 0 -100
- Menghitung nilai akhir
- Menentukan predikat dan status kelulusan
- Memberikan Rekomendasi
